    レポートの作成について

    提出について

    提出方法

    Microsoft Teams に課題を設定しますので，期限までに提出してください．

    提出物

    以下の2つを提出してください．

    • レポート（PDF形式）
      • ファイル名は 学籍番号-課題番号.pdf としてください．
        • 例えば学籍番号がC224099，課題番号がR1なら，C224099-R1.pdf としてください．
      • Word 形式（*.docx）のまま提出しないでください．
    • ソースコード
      • ファイル名は 学籍番号-課題番号.c としてください．

    内容について

    様式

    以下の要件を満たさないレポートは減点対象となります．

    • 要件１：以下のサンプルの形式に従うこと．
      • サンプルレポート（Word形式）
        • 手書きのレポートは認めません．
        • 用紙のサイズはA4・縦向きとしてください．
        • サンプルは1-カラム形式ですが，2-カラム形式にしてもかまいません． ただし，レイアウトが乱れた場合減点対象となります．
    • 要件２：フォントサイズや形式などがレポートを通して統一されていること．
      • 本文の和文フォントは「MS P明朝 10.5pt」を推奨します．

    構成

    レポートの章立ては以下の通りとしてください．

    1. 概要
    2. プログラムの構造
    3. 関数の実装
    4. 実行例
    5. 参考文献

    各章で書くべきこと

    1. 概要

    • 課題として，解決するべき事項について書いてください．

    例

    本課題では，標準入出力から西暦年と月が与えられたとき，その月のカレンダーを標準入出力に出力するCプログラムcal.cの作成を目的とする．

    2. プログラムの構造

    • 入出力を含む処理の流れを説明してください．
      • フローチャートなどを用いてわかりやすく説明すること．
      • どの処理がどの関数で実現されるかを書いてください．
      • 関数内で行われる詳細な処理までは踏み込んで書かないでください．
        • それについては「3. 関数の実装」で書いてください．

    例

    cal.cの処理構造をフローチャートとして図1に示す．cal.cでは，まず，標準入出力から西暦年と月を入力する．そして，その月の総日数を求め，その月の一日の曜日を求める．その上で一日の曜日と月の日数を元に，その月のカレンダーを標準入出力へと出力する．

    （図1は省略）

    この処理1を関数days_of_month，処理2を関数day_of_week，処理3を関数print_monthとしてそれぞれ実装する．

    3. 関数の実装

    • プログラム中の作成した全ての関数について，引数・戻り値について説明した上で，それをどのように実装したかを説明してください．
      • 必要に応じてソースコードを適宜引用してください．
      • 図や表を用いてできるだけわかりやすく説明すること．
    • 「2. プログラムの構造」と合わせて「1. 概要」で示された課題がきちんと解決されていることがわかるように書くこと．

    例

    (1) days_of_month 関数days_of_monthは，西暦年と月が与えられたとき，その月の総日数を求める．引数として西暦年を表す整数型の変数yearおよび月を表す整数型の変数monthをもち，戻り値として総日数を表す整数を返す．関数days_of_monthの処理構造をフローチャートとして図2に示す．関数days_of_monthでは，まず，与えられたmonthの値が1,3,5,7,8,10,または12のいずれかであれば戻り値として31を返す．monthの値がこれらの値でなく，かつ2でなければ戻り値として30を返す．そのどちらでもないとき，すなわちmonthの値が2ならば，与えられた西暦年yearが閏年であるかどうかを判定する．その結果，yearが閏年であれば戻り値として29を返し，そうでなければ戻り値として28を返す．

    （図2は省略）

    4. 実行例

    • 実行例は，作成したプログラムによって「1. 概要」で示した課題を解決したことを示すために載せるものです．ですので，その実行結果によって何が示されたのか必ず説明してください．
      • 説明も無く結果を貼りつけるだけにしないこと．
    • 不正な入力について，どのような結果を返すかについても説明すること．

    5. 参考文献

    • レポートを作成する上で参照したものをリストアップして番号をつけ，本文中の関連する部分に対応した番号を書いてください．
      • 「文献」だが，書籍に限りません．Webページなどでもかまいませんが，最終閲覧日を記載してください．
    • 最低限必要な情報としては以下となります．
      • 書籍の場合
        • 著者名
        • タイトル
        • 出版社
        • 出版年
      • Webページの場合
        • タイトル
        • URL
        • 最終閲覧日
    • 本文での登場順に番号をつけてください．

    例

    本プログラムでは，グレゴリオ暦に基づいて閏年の判定を行う．グレゴリオ暦では，

    1. 西暦年が4で割り切れる年は，閏年とする．
    2. ただし，西暦年が100で割り切れる年は，平年とする．
    3. ただし，西暦年を400で割り切れる年は，閏年とする．

    という規則に従って閏年が設けられる[1]．

    （中略）
